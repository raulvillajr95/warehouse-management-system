# Warehouse Management System

A full-stack warehouse management system built with React, Node.js, Express, and PostgreSQL.

## Overview

This project simulates software used in modern warehouses to manage inventory, orders, and operational analytics.

The goal is to build a production-quality application while demonstrating full-stack software engineering skills.

## Planned Features

- Authentication
- Inventory Management
- Order Management
- Warehouse Dashboard
- Low Stock Alerts
- Search & Filtering

## Tech Stack

**Frontend**
- React
- TypeScript
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- PostgreSQL
- Prisma ORM
